# FinanceML

A fun, experimental project about finance I made after discovering Machine Learning and it's outstanding ability to adapt to input, giving desired output.<br><br>
I am using XGBoost for this, datas fed from yfinance and the desired output is 1/0s<br>=>up or down
--
**To ensure everything will work, do these in cmd:**<br>
*pip install xgboost*<br>
*pip install scikit-learn*<br>
*pip install pandas*<br>
*pip install yfinance*<br>
<br><br>
